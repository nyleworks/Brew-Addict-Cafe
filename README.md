# Brew Addict Cafe

Website for Brew Addict Cafe in Kundasang, Sabah. Plain HTML, CSS and JavaScript with no build step: open `index.html` in a browser.

- `index.html` – page markup
- `styles.css` – styles
- `script.js` – menu data, EN/BM copy and scroll animations
- `stamp-card.js` – stamp card tab and panel (talks to the Google Sheet backend)
- `apps-script/Code.gs` – stamp card backend for Google Apps Script; setup steps in `STAMP-CARD-SETUP.md`
- `images/signboard.webp` – hero signboard
- `images/mascot.png` – mascot used on the stamps
- `og-image.png` – social share image
